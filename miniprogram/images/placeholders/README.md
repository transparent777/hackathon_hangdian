# UI 占位素材

准备好后按文件名覆盖即可，无需改代码（Tab 图标除外）。

| 文件 | 用途 | 建议尺寸 |
|------|------|----------|
| `home-banner.jpg` | 首页顶部大图 | 750×400px，< 200KB |
| `tab-home.png` / `tab-home-active.png` | Tab 首页图标 | 81×81 透明 PNG |
| `tab-history.png` / `tab-history-active.png` | Tab 历史图标 | 同上 |
| `tab-me.png` / `tab-me-active.png` | Tab 我的图标 | 同上 |
| `empty-history.png` | 历史空状态（可选） | 300×300 |

当前 Banner 使用 `home-banner.svg` 渐变占位；放入 `home-banner.jpg` 后自动优先显示。
