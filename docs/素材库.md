# 素材库说明

`素材库/` **不会进入 Git**（见根目录 `.gitignore`）。每人本地维护自己的源文件，通过脚本或手动复制到 `miniprogram/` 后再提交小程序资源。

## 目录结构（本地）

```
素材库/
├── 封面/              # 开场视频（开场.mp4、开场2.0.mp4）
├── 主页/
│   ├── banner.jpg     # 首页顶部封面
│   └── 陪伴兽/
│       ├── 奶蛙/      # 普通.jpg · 稀有.jpg · 传说.jpg
│       ├── doro/
│       └── 耄耋/
├── 陪伴空间/          # 陪伴日记 UI
│   ├── 相框1.png
│   ├── 相框2.png
│   └── 草稿纸背景.jpg
├── 溶图/              # 溶图角色素材（多角度 / 表情 / 姿势）
│   ├── naiwa/         # 奶蛙
│   ├── doro/
│   └── maodie/        # 耄耋
└── 小程序模板/        # 仅参考，不直接引用
```

## 同步到小程序（提交 Git 的是这些）

| 源文件 | 目标路径 |
|--------|----------|
| `主页/banner.jpg` | `miniprogram/images/placeholders/home-banner.jpg` |
| `主页/陪伴兽/{角色}/{稀有度}.jpg` | `miniprogram/images/characters/covers/{id}/{normal\|rare\|legendary}.jpg` |
| `封面/开场2.0.mp4` | 压缩后 → `miniprogram/assets/splash/intro.mp4` |
| `陪伴空间/相框1.png` | `miniprogram/images/diary/polaroid-frame-1.png` |
| `陪伴空间/相框2.png` | `miniprogram/images/diary/polaroid-frame-2.png` |
| `陪伴空间/草稿纸背景.jpg` | `miniprogram/images/diary/draft-paper-bg.jpg` |

角色 ID 映射：奶蛙 → `naiwa`，doro → `doro`，耄耋 → `maodie`  
稀有度映射：普通 → `normal`，稀有 → `rare`，传说 → `legendary`

## 体积限制（微信上传要求）

| 类型 | 上限 |
|------|------|
| 图像 / 短音频 | **≤ 200KB** |
| 开场视频 `intro.mp4` | **≤ 1.5MB**（1080p H.264，保证可上传且清晰） |

上传前检查：

```bash
python scripts/check_assets_size.py
```

## 一键同步（图像压到 200KB，开场视频压到 1.5MB 以内）

```bash
python scripts/sync_assets.py
# 仅同步陪伴日记素材（相框 / 草稿纸）：
python scripts/sync_diary_assets.py
# 溶图角色素材 → ai/references/variants/ + manifest.json：
python scripts/sync_blend_assets.py
```

### 溶图素材

| 源目录 | 目标 |
|--------|------|
| `溶图/{naiwa\|doro\|maodie}/*` | `ai/references/variants/{角色}/01.jpg …` |
| 手动选定主参考图 | `ai/references/{角色}.jpg`（溶图 API 默认使用） |

清单见 `ai/references/manifest.json`（标记哪张是主参考图 `isPrimary`）。

## 若素材库曾被误提交

```bash
git rm -r --cached 素材库/
```
