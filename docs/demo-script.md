# 30 秒 Demo 录屏脚本

> 用于答辩备用视频 / 体验版审核来不及时的展示

| 时间 | 画面 | 旁白（可选） |
|------|------|-------------|
| 0–3s | 开场动画 → 跳过 | 「赛博陪伴相机」 |
| 3–8s | 首页点 **抽取陪伴兽** | 「每天随机 roll 一只陪伴兽」 |
| 8–12s | 点 **进入溶图** → 选一张书桌/窗边照片 | 「拍一张真实生活场景」 |
| 12–18s | 溶图 loading → 结果页 | 「AI 把 TA 溶进你的照片」 |
| 18–22s | 展示陪伴语，点 **保存到相册** | 「生成专属陪伴瞬间」 |
| 22–26s | 切到 **历史** Tab | 「记录都会留下来」 |
| 26–30s | **我的 → 陪伴日记** 下滑一条 | 「还有 AI 手账式陪伴日记」 |

**录制提示**：竖屏、关闭开发者工具调试条、Mock 模式下确保溶图 2 秒内完成。
